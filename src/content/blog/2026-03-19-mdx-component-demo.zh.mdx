# 在 Markdown 中使用自定义组件

虽然我们的博客系统使用 `react-markdown` 来渲染 Markdown 内容，但你仍然可以通过 HTML 标签的方式使用自定义组件。

## 使用 Callout 组件

`Callout` 组件用于创建带有表情符号和标题的提示框：

<callout emoji="💡" title="小知识">
这是一个蓝色的 Callout 组件，用于展示重要但不紧急的信息。
</callout>

<callout emoji="⚠️" title="注意" color="red">
这是一个红色的 Callout 组件，用于警告用户注意潜在的问题。
</callout>

<callout emoji="✅" title="成功" color="green">
这是一个绿色的 Callout 组件，用于表示操作成功或推荐的做法。
</callout>

<callout emoji="🎨" title="自定义颜色" color="purple">
Callout 组件支持多种颜色：`default`、`blue`、`green`、`red`、`purple`。
</callout>

## 使用 Alert 组件

`Alert` 组件用于创建不同级别的警告信息：

<alert type="note">
这是 `note` 类型的警告，用于提供补充说明信息。
</alert>

<alert type="tip">
这是 `tip` 类型的警告，用于提供有用的技巧和提示。
</alert>

<alert type="warning">
这是 `warning` 类型的警告，用于提醒用户注意潜在问题。
</alert>

## 使用方法总结

| 组件 | 用法 | 支持的属性 |
|------|------|-----------|
| `Callout` | `<callout emoji="💡" title="标题" color="blue">内容</callout>` | `emoji`, `title`, `color` |
| `Alert` | `<alert type="note">内容</alert>` | `type` (note/tip/warning/caution/important) |

## 注意事项

1. 组件标签必须使用小写（如 `<callout>` 而不是 `<Callout>`）
2. 属性值需要用引号包裹
3. 组件内容可以是 Markdown 语法
4. 确保组件在 `MDXContent.tsx` 中已注册
